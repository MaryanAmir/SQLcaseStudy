
# IPL Player Analytics using SQL Server

This project contains SQL analysis queries performed on an IPL players dataset using SQL Server Management Studio (SSMS).

## Skills Used
- SQL Queries
- CTEs
- Window Functions
- Aggregate Functions
- Ranking Functions
- Conditional Aggregation
- Subqueries

## Business Questions Solved
- Team spending analysis
- Top-paid players by team
- Ranking players within teams
- Player contribution percentage
- Average team spending comparison
- Win percentage analysis
- Match statistics analysis

## Tools
- SQL Server Management Studio (SSMS)
- SQL Server

## Project Goal
Practice solving business-style SQL problems and improve analytical thinking using SQL.
